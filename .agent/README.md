# Documentación de Gestión del Proyecto

Este directorio contiene la documentación de gestión y planificación del proyecto Collaborative Saving.

## 📁 Estructura

```
.agent/
├── roadmap.md              # Roadmap estratégico (Corto/Mediano/Largo plazo)
├── change-management.md    # Workflow de gestión de cambios con Notion
├── notion-workflow.md      # Configuración del flujo de trabajo acordado
├── skills/                 # Skills de Antigravity
├── workflows/              # Workflows automatizados
└── docs/                   # Documentación adicional
```

## 🎯 Documentos Principales

### [roadmap.md](./roadmap.md)
Hoja de ruta estratégica dividida en 3 fases:
- 🟢 **Corto Plazo (1-2 meses):** Flexibilidad y estabilización
- 🔵 **Mediano Plazo (3-5 meses):** Multi-tenancy y escalabilidad
- 🟣 **Largo Plazo (6+ meses):** SaaS y valor agregado

### [change-management.md](./change-management.md)
Sistema completo de gestión de cambios que integra Antigravity con Notion:
- Flujo de trabajo (Inicio → Desarrollo → Revisión)
- 3 Templates de Notion (Funcionalidad, Bug, Refactorización)
- Estándares de Git (commits, ramas)
- Métricas de seguimiento

### [notion-workflow.md](./notion-workflow.md)
Configuración acordada del flujo de trabajo:
- Revisión cada 3 días
- Comunicación vía comentarios en Notion
- Convenciones y formato de commits

## 🔗 Notion

**Base de Datos:** [Roadmap - Tareas del Proyecto](https://www.notion.so/040f52b94bc5405caccb5f4a5b53cd5b)

**Total de tareas:** 19

- Mediano Plazo: 5 tareas
- Largo Plazo: 6 tareas

## 🚀 Cómo Usar

1. **Para planificar nueva funcionalidad:**
   - Crear tarea en Notion usando template "Funcionalidad Nueva"
   - Seguir el flujo definido en `change-management.md`

2. **Para revisar progreso:**
   - Revisar comentarios en Notion cada 3 días
   - Consultar `roadmap.md` para contexto estratégico

3. **Para contribuir:**
   - Seguir convenciones de Git en `notion-workflow.md`
   - Referenciar ID de tarea de Notion en commits
