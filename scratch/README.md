# Scratchpad Directory 🛠️

Este directorio está destinado a pruebas rápidas, scripts desechables, experimentos locales y notas temporales durante el desarrollo.

## Reglas de Seguridad y Buenas Prácticas

1. **Sin datos reales ni PII:** Está estrictamente prohibido guardar o commitear volcados de bases de datos (`.sql`, `.dump`), archivos con información personal identificable (PII) o registros financieros reales.
2. **Sin credenciales ni secretos:** Nunca coloques claves privadas, credenciales de servicios (`*-adminsdk-*.json`), tokens de acceso o variables de entorno con secretos aquí.
3. **Ignorado por Git:** Todo el contenido de este directorio (a excepción de este archivo `README.md`) está excluido en el `.gitignore` raíz para evitar filtraciones accidentales de archivos de desarrollo local.
