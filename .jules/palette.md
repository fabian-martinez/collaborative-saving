## 2024-05-24 - Accessibility standards for disabled buttons
**Learning:** Native HTML \`title\` attributes do not appear when placed on disabled buttons (e.g. \`<button disabled>\`) because disabled elements do not receive mouse or pointer events in most major browsers. To ensure that tooltips explaining the disabled state are accessible, the tooltip container (e.g. DaisyUI's \`.tooltip\` class) should wrap the button, so that hover events trigger on the wrapper instead.
**Action:** When adding tooltips to buttons that can enter a disabled state, wrap the button in an element with a tooltip class or implement the tooltip on an outer \`div\` or \`span\` wrapper to guarantee it remains visible when the button itself is disabled.

## 2024-06-01 - Add aria-label to DaisyUI modal backdrop close buttons
**Learning:** In DaisyUI modals, the common pattern `<form method="dialog" class="modal-backdrop"><button>close</button></form>` provides an accessible way to close the modal when clicking outside of it. However, the inner button text ("close") is visually hidden and may not be sufficiently localized or descriptive for screen reader users in a non-English application.
**Action:** When using the DaisyUI modal backdrop pattern, always ensure the inner button has a descriptive and localized `aria-label` (e.g., `aria-label="Cerrar modal"`) to provide clear context for assistive technologies.
