# Contexto de Negocio

## Qué es Collaborative Saving

Collaborative Saving es una plataforma moderna para la gestión de grupos de ahorro comunitario. Maneja aportes de socios, suscripciones de acciones, préstamos y registros financieros complejos mediante un sistema de contabilidad de partida doble.

## Quién paga por esto

El sistema está diseñado para ser financiado por los propios socios del fondo de ahorro a través de sus aportes y los intereses generados por los préstamos.

## Ecosistema

- **Backend (V2):** API REST robusta construida con NestJS.
- **Frontend (V2):** Interfaz de usuario moderna construida con Vue 3.
- **Base de Datos:** PostgreSQL gestionado vía Supabase.

## Voz de marca / tono

- **Transparencia:** Cada centavo debe ser rastreable.
- **Simplicidad:** Los conceptos contables complejos se presentan de forma digerible.
- **Seguridad:** Los datos financieros de los socios son sagrados.
